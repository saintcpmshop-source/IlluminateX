### 🌟 What is IlluminateX?

**IlluminateX** is a premium, high-end utility suite designed exclusively for CFW (Custom Firmware) PlayStation 3 consoles. It shatters the mold of clunky, outdated PS3 homebrew by offering a centralized, sleek, and modern interface. 

### ⚡ Ultimate Features
*   **💾 Storage Hub:** View internal HDD and USB statuses, scan for ISOs, and manage your game library.
*   **🌐 Network Center:** Built-in FTP management for fast, wireless PC-to-PS3 file transfers.
*   **🌡️ System Monitor:** Real-time CPU/RSX temperature tracking and manual fan speed overrides.
*   **🎨 P3T Theme Hub:** Browse a curated gallery of custom PlayStation 3 Themes with one-click download.
