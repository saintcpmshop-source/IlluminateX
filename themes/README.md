# 📁 IlluminateX Theme Submissions

Welcome to the official theme repository for **IlluminateX**!

We are always looking for new themes to feature in the IlluminateX dashboard.

**How to submit your theme:**
To ensure quality and compatibility, we do not accept direct Pull Requests for themes. Instead, please join our Discord server and open a support ticket with your `.p3t` file and a screenshot.

👉 **[Join our Discord Server to Submit Themes!]([YOUR_DISCORD_INVITE_LINK])**

Once approved by the **saintcpmshop-source** team, your theme will be added to the official dashboard.
